## 你一般是怎么解决技术问题的？

When I face a technical problem, I first reproduce it — I need to see it consistently to understand the trigger. Then I check the logs and error messages carefully.

After that, I make a guess about what's wrong, and I test it with a small, safe experiment but not a big code change. If it is wrong, I try another way.

If I can't solve it on my own, I'll search for error messages on Google or Stack Overflow. Of course, Now, I can ask an LLM directly.

If still stuck, I discuss with teammates.

## 描述一次你克服挑战的经历

One time, my RAG system had a hallucination issue. I checked the logs and found that we got chunk with answer, but it was missing important information that was actually in the next chunk. The root cause was that a long text had been split into two chunks.

So I improved the chunking logic. When a large block of text needs to be split, I treat it as a parent chunk and split it into child chunks. If a child chunk is retrieved, I also retrieve the parent chunk. This keeps the semantics connected.

The issue was resolved after that.
