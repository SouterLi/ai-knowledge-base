**关于本职位**  
您将负责端到端的架构设计、构建与部署，涵盖：
- 能够执行复杂工作流的代理型系统（例如：**规划并执行多步任务**）
- **使用工具**的LLM系统（检索、函数调用、代码执行、浏览等）
- **多智能体**编排框架
- **长期记忆**架构（向量 + 结构化状态）
- 用于**可靠性、幻觉检测和安全性**的**评估框架**
- 生产级推理管道（**延迟、扩缩容、可观测性**）
- **护栏**与**后备系统**
    

**岗位职责**
- 端到端设计并构建生产级代理型AI系统，包括规划与执行循环、状态化记忆、安全的工具调用、沙箱化执行，以及稳健的重试与反思机制
- 部署并运行经延迟和成本优化的可扩缩推理基础设施，通过日志记录、追踪、评估指标以及针对漂移和故障模式的主动监控，实现良好的可观测性
- 通过开发自动化评估管道、面向产品的基准测试以及针对推理性能的压力测试，建立严格的可靠性和安全性框架
- 实施护栏与治理控制，包括约束系统、幻觉缓解、权限管理、审计追踪和人机协作工作流，确保真实环境下的安全可靠运行
    

**任职资格**

- 在软件工程或AI系统方面有成熟经验，尤其是设计并在生产环境中交付过基于LLM的系统
- 熟练掌握AI原生开发工具，如Claude Code、Cursor或同类AI编程助手，并能利用这些工具加速软件开发生命周期
- 深刻理解工具调用/函数调用、RAG架构、向量数据库、提示链与规划器/执行器模型的区别、延迟优化及成本权衡
- 具有部署云原生系统的经验
- 熟悉可观测性技术栈（指标、追踪、日志记录）及生产监控实践
- 优先考虑：开源AI工具贡献者
- 示例技术栈：Python、FastAPI、LLM API 与开源权重模型、向量数据库、Kubernetes / Serverless 部署
