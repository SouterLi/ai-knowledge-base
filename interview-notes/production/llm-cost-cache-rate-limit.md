# LLM 应用成本、缓存与限流设计

## 主题选择记录

- **主题**：LLM 成本、缓存与限流
- **分类**：生产化工程
- **仓库去重**：与 RAG、Agent、评估等互补，聚焦**线上成本与流量治理**
- **适用岗位**：AI 应用开发、平台/后端工程师

## 核心概念

上线后难点常从「调通 API」变成**成本、延迟、稳定性**。成本不止主模型账单：输入 token（system、历史、RAG）、输出 token、Embedding/Rerank/改写/审核等辅助调用都要算进去。原则：**先观测再优化**，不能只说换小模型。

**缓存**用空间换时间和钱；**限流**保护系统和预算。二者都要带**权限、模型版本、Prompt 版本**，否则误命中越权或过期答案。

## 核心知识点

### 1. 成本拆解

| 来源 | 优化杠杆 |
|------|----------|
| 输入 token | 压缩历史、减 RAG top_k、摘要索引 |
| 输出 token | max_tokens、要求简洁、避免无限续写 |
| 辅助调用 | 缓存 Embedding、减少 rewrite 次数 |
| 模型选型 | 路由：简单用小模型，复杂再升级 |

### 2. 缓存类型

- **精确缓存**：query 归一化后 key 完全一致，适合 FAQ、分类。
- **语义缓存**：embedding 相似度 > 阈值命中；要防「相似但意图不同」。
- **检索缓存**：RAG 召回/Rerank 结果。
- **前缀缓存**：固定 system、工具说明、长文档前缀（部分厂商支持 prompt cache）。

```python
def cache_key(model: str, prompt_ver: str, scope: str, q: str) -> str:
    # scope = tenant_id + role，避免跨租户命中
    return f"{model}:{prompt_ver}:{scope}:{normalize(q)}"
```

### 3. 语义缓存风险

相似≠等价；权限不同、时效不同、个性化条件不同都可能误命中。高风险场景可只缓存检索片段，不缓存最终答案；阈值保守 + 人工抽检误命中率。

### 4. 限流与预算

令牌桶/滑动窗口；维度：用户、租户、API、模型、RPM/TPM、并发、日预算。限流目标：**保护系统**与**公平配额**——核心租户保留额度，低优先级任务异步化。

### 5. 模型路由（Router）

用小模型或规则做意图/复杂度分类，简单问答走便宜模型，复杂推理再走强模型。用离线评测验证质量不掉太多。

### 6. 降级策略

超预算：排队、异步、返回简化答案、关闭 Rerank/多查询等非核心链路。重试带上限，区分 429 限流与 5xx。

### 7. 观测指标

P95/P99 延迟与 token、单次请求成本、缓存命中率/误命中率、限流触发次数、按业务场景的费用分布。

## 高频面试问题与标准答案

### 1. 如何降低线上 LLM 成本？

我习惯先拉一周账单按场景拆：哪个功能 input 最长、哪个 output 失控。然后针对性做——压 RAG 上下文、限 max_tokens、高频精确缓存、简单问路由小模型、批处理 Embedding。每步用监控验证省了多少钱、质量掉没掉。

### 2. 语义缓存怎么做才安全？

缓存键必须含租户/用户权限范围、模型和 Prompt 版本；阈值别太激进；对退款、医疗、账户类问题我会禁用答案缓存或只缓存检索。上线后盯误命中案例。

### 3. 流量突增怎么处理？

组合：租户级限流、队列削峰、热点精确缓存、临时关 Rerank、非核心功能降级、必要时熔断模型供应商。要和产品说清楚是「排队」还是「直接拒绝」，别 silent drop 用户请求。

### 4. 为什么缓存要考虑 Prompt 版本？

改一句 system 规则，答案语义可能全变。不带 `prompt_version` 会把旧逻辑下的缓存喂给用户，排查非常痛苦。

### 5. 精确缓存和语义缓存怎么选？

FAQ、固定分类用精确；口语变体多的用语义，但要评测误命中。很多团队先上精确，语义缓存在有 embeddings 基建后再加。

### 6. 如何控制输出 token 成本？

设 `max_tokens`、在 Prompt 里要求条目化短答、对长报告改异步任务而不是聊天流式一直生成。监控 output token P99，异常高的请求单独分析。

### 7. 重试会不会把成本打爆？

会。我会对 429/5xx 做有限次指数退避，并设每用户每日重试上限。客户端也要幂等，避免双击产生双倍调用。

### 8. 限流和降级有什么区别？

限流是「不让进或慢进」；降级是「进了但用更便宜/更简单的路径完成」。面试里最好两个都提到，体现生产思维。

### 9. 如何向老板证明优化有效？

优化前后对比：日均费用、P95 延迟、核心场景准确率/采纳率。只报省了多少钱不说质量，业务不会买账。

### 10. 成本优化和安全冲突时怎么取舍？

权限过滤必须在缓存**写入和读取**前都做。为了命中率把跨租户内容放进共享缓存，属于严重事故，不能妥协。
