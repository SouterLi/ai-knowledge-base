# AI 应用开发面试笔记

> 一本面向 **AI 应用开发 / LLM 应用 / Agent·RAG 工程师** 岗位的面试复习手册。  
> 正文位于 `docs/知识库/`，每篇围绕「核心概念 → 核心知识点 → 面试表达」组织；部分主题配有独立的面试问答稿，便于口述练习。

---

## 关于本书

企业里的大模型应用，面试很少只问「API 怎么调」，更常追问 **能不能落地、能不能稳住、能不能量化改进**。本仓库把这类问题拆成可复习的专题：从 Prompt、RAG、Agent 到工作流编排、生产化、安全与 LLMOps，尽量用工程视角写清楚设计取舍，而不是概念罗列。

**适合谁读**

- 准备 AI 应用开发、LLM 平台、智能客服 / 知识库、Agent 方向面试的工程师  
- 已在写 RAG / Agent 产品，希望系统化补全知识盲区的开发者  

**怎么读**

- **冲刺复习**：按目录 **第 1～12 篇** 顺序阅读，覆盖绝大多数一面、二面高频点。  
- **岗位加深**：知识库 / 问答岗重点看 2、5～7、23、31～32、35、46；Agent / 应用入口岗重点看 3、8、13、16、22、38、40、42～43；平台 / 基建岗重点看 10～12、14、17、20～21、28～29、34、36～37、39、41、44；安全合规岗重点看 9、18～19、45、47；文档智能 / 多模态岗重点看 26、33。
- **专题串联**：同一主题多篇（如 RAG 九篇）建议先读第 2 篇总览，再读 5～7、23、31～32、35、46；Agent 主题可先读 3、8，再读 16、22、30、40、42～43；工作流主题可先读正文，再用配套面试问答练口述。

**编号说明**：下表序号按 **面试出现频率、岗位通用性、知识依赖关系** 综合排序，**数字越小越优先**；「卷」仅作主题归类，复习顺序以序号为准。

**卷次与篇次对应**

- **基础能力（1～4、38）**：Prompt、RAG 总览、Agent 工具、上下文、意图识别与任务路由——几乎所有岗位必问。
- **RAG 工程化（2、5～7、23、31～32、35、46）**：摄取切分、向量索引、重排压缩、GraphRAG、查询理解与路由检索、答案生成与引用归因、权限过滤与 ACL 检索、混合检索与多路召回融合——知识库 / 问答岗深度考点。
- **Agent 与编排（3、8、13、16、22、30、40、42～43）**：工具调用、可靠性、工作流与 HITL、MCP、多 Agent、工具执行沙箱、Agent 评估与轨迹分析、会话状态与检查点恢复、工具执行幂等与补偿——Agent 方向核心。
- **安全与合规（9、18、19、45、47）**：提示注入、越权、多租户、隐私脱敏、数据治理、红队测试与安全评测、内容安全与合规审核——企业落地必谈。
- **生产化与 LLMOps（10、11、14、17、20、21、28、29、34、36～37、39、44）**：评估、成本、网关、测试、发布、数据闭环、私有化部署、输出契约、结果一致性治理、高并发容量规划与弹性伸缩、故障演练与降级预案、评测集构建与数据标注、语义缓存设计与一致性治理。
- **运行时与性能（12、24、41）**：流式、异步、端到端延迟、推理加速与服务端调度——体验与 SLA。
- **数据与查询（15）**：Text-to-SQL / NL2SQL——数据分析与业务系统结合场景。  
- **专项进阶（25～27、33）**：微调、多模态、语音、复杂表格文档解析与结构化抽取——按岗位选读。
